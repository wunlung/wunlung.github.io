## Context

EVA was built by MCPioneers, a three-person team, for the inaugural Optus × GitHub Copilot Hack-AI-thon. The goal was to use AI to improve developer experience around a real user need rather than demonstrate technology in isolation.

## Approach

The project brought together modern AI building blocks—including large language models, retrieval-augmented generation, and the Model Context Protocol—within one developer-facing assistant.

The supplied public material does not document enough detail to describe EVA’s workflow or architecture responsibly. This case study will expand when the user scenarios, system design, and my precise implementation contribution are ready for public disclosure.

## Outcome

EVA received the event’s top prize. The result reflected the team’s execution, diligence, and close collaboration under a compressed hackathon schedule.

## Lessons

Three ideas stayed with me:

1. Hackathons compress the learning loop: absorb, apply, test, and adapt.
2. Useful AI products often combine several specialised building blocks rather than rely on one model call.
3. Empathy is a technical advantage. The strongest solution begins with what the user is trying to accomplish.

The project reinforced my preferred way to keep up with AI: stay curious, build, fail, iterate, and share what I learn.
